Conecta tu Instagram

Esto se hace una sola vez. El token se guarda solo en este navegador de tu PC y nunca queda escrito en el archivo.

  1. Entra a developers.facebook.com/apps y abre tu app.
  2. Ve a Casos de uso → Personalizar el de Instagram, y abre API setup with Unified login (o API setup with Instagram login, según tu app).
  3. En 2. Generar tokens de acceso, agrega @andres.overtone y pulsa Generar token.
  4. Copia el token y pégalo aquí. Si empieza por EAA, deja también el ID numérico de tu cuenta (el número que sale bajo tu usuario).
